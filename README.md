# CampusRide — Студенттердің бірлескен сапар сервисі

## 1. Команда және рөлдер
* **Команда:** Team 3
* **Жоба тақырыбы:** №5 — Студенттердің бірлескен сапар сервисі / CampusRide
* **Пәндер:** Frameworks + Application Development Based on Design Patterns
* **Мүшелер және рөлдер:**
  * **Қайрат Ердана** — Team Lead / Architect, Backend Developer, Frontend Developer, QA & DevOps Engineer *(Уақытша жалғыз өзі)*

## 2. Жобаның сипаттамасы
* **Шешілетін мәселе:** Таңертеңгі және кешкі қарбалас уақытта студенттердің оқу корпустарына (мысалы, ЛесФАК, Бас корпус) жетуі қиын әрі такси бағасы қымбат. Сонымен қатар, жеке көлігі бар студенттер бос орындармен жүреді.
* **Шешім:** Бір бағытта жүретін студенттерді біріктіретін, жол ақысын бөлісуге және қауіпсіз сапар ұйымдастыруға мүмкіндік беретін веб-платформа.
* **Мақсатты аудитория:** Университет студенттері мен оқытушылары.

## 3. Негізгі функционал (MVP)
1. **Тіркелу және авторизация:** Студенттік пошта немесе ID арқылы жүйеге кіру (Рөлдер: Жүргізуші / Жолаушы).
2. **Сапар жариялау (Жүргізуші):** Бағытты (А нүктесі — Б нүктесі), уақытты, бос орындар санын және жол ақысын көрсету.
3. **Сапар іздеу және брондау (Жолаушы):** Қажетті бағыт пен уақыт бойынша сапарларды сүзу және орын брондау.
4. **Басқару панелі:** Белсенді және аяқталған сапарлар тарихын көру, броньды растау немесе бас тарту.

## 4. Технологиялық стек және архитектура
* **Backend:** C# / ASP.NET Core Web API
* **Frontend:** HTML, CSS, JavaScript (немесе React / Razor)
* **Дерекқор:** PostgreSQL / MS SQL Server
* **Жобалау паттерндері (Design Patterns):**
  * **Repository & Unit of Work** — дерекқормен жұмысты абстракциялау үшін.
  * **Factory Method / Strategy** — сапар құнын есептеу және хабарламалар жіберу логикасы үшін.
  * **Observer** — брондау мәртебесі өзгергенде пайдаланушыларға ескерту жіберу үшін.
* **DevOps & Version Control:** Git, GitHub (Branch Protection ережелері қосылған).
