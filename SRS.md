
# Software Requirements Specification (SRS) for CampusRide

## 1. Introduction
CampusRide is a shared mobility platform designed for university students to share rides.

## 2. User Roles
* **Driver**: Offers rides and sets routes.
* **Passenger**: Searches and books rides.
* **Admin**: Manages users and disputes.

## 3. Functional Requirements
* **US-01**: University email login.
* **US-02**: Create trips with details.
* **US-03**: Filter and book trips.
* **US-04**: View trip history.
* **US-05**: Driver trip cancellation.
* **US-06**: Passenger booking cancellation.
* **US-07**: Cost calculation.
* **US-08**: In-app chat.
* **US-09**: User ratings.
* **US-10**: SOS emergency button.
* **US-11**: Push notifications.
* **US-12**: Admin management dashboard.

## 4. Non-Functional Requirements
* **Security**: Data encryption.
* **Performance**: 2-second load time.
* **Availability**: 99.9% uptime.
* **Scalability**: Handle concurrent users.
